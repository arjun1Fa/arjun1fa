## selected work

<br>

**NutriVision**

ai-powered food detection and nutritional analysis system. point your phone camera at food — it identifies items using YOLOv8, estimates portion sizes, and calculates nutritional values in real time.

`Python` `PyTorch` `YOLOv8` `Flutter` `Flask` `OpenCV`

[repository ↗](https://github.com/arjun1Fa/Mini_Project)

<br>

**Hospital Nav**

indoor hospital navigation system using graph-based routing, CLIP vision for location recognition, wifi fingerprinting for positioning, and ar overlays for real-time guidance. built with flutter frontend and fastapi backend.

`Flutter` `FastAPI` `CLIP` `WiFi Fingerprinting` `AR` `Python`

[repository ↗](https://github.com/arjun1Fa/hospital-nav)

<br>

**TinkerHub Project**

full-stack application built during a tinkerhub event. typescript-based project focused on rapid prototyping and collaborative development.

`TypeScript` `React`

[repository ↗](https://github.com/arjun1Fa/TInker_hub)

<br>

**Tournament Tracker**

sports tournament management system — handles team registration, match scheduling, score tracking, and bracket generation for college events.

`Python`

[repository ↗](https://github.com/arjun1Fa/tournament_tracker_pes)

<br>

**Hostel Food Management**

system for managing hostel food operations — menu planning, student preferences, waste tracking, and meal scheduling.

`Python`

[repository ↗](https://github.com/arjun1Fa/hostel_food_management)

<br>

**Syllabus Tracker**

a flutter app to track syllabus completion for university exams. helps students visualize progress and prioritize remaining topics.

`Dart` `Flutter`

[repository ↗](https://github.com/arjun1Fa/Syllabus_tracker)

<br>

**11:11 Hackathon**

hackathon project — a flutter-based mobile application built under time constraints. received community engagement with stars and forks.

`Dart` `Flutter`

[repository ↗](https://github.com/arjun1Fa/11_11_hackathon)

## what i like building

i like building things that solve an actual problem — or at least a problem i personally find annoying enough to fix.

most projects start as a random idea at 2am and somehow become a working system. the hospital navigation project started because i got lost in a hospital. nutrivision started because i wanted to know how many calories were in my mess food.

if there's a camera, a model, and a real-world problem, i'm probably building something for it.
